작업 공간

사용할 수 있는 기능

  • 원고 입력 P-01
    원고 원본을 비공개 보관함에 보관하고 쪽별 글자를 꺼냅니다. 글자층이 없거나 깨진 PDF는 그 쪽만 OCR로 읽고, 추출 가능한 원본 요청을 관리합니다.
  • 변환 확인 P-02 · P-16 · P-17
    PDF 원고를 구조화 블록으로 바꿉니다. 2단 읽기 순서, 줄 단위로 끊긴 문단 잇기, 캡션·그림 속 글자 분리를 자동으로 하고, 사람이 쪽마다 원본 옆에서 확인·수정합니다.
  • 편집 지시문 S-01
    저자가 원고 속에 남긴 편집자용 작업 지시를 변환 저장 때 자동으로 찾아 본문에서 뺍니다(그대로 인쇄되는 사고 방지). 애매한 문장은 본문에 둔 채 판정을 기다리고, 판정 전에는 원고를 확인 완료로 바꿀 수 없습니다.
  • 그림 원본 검수 S-02
    AI 그림 판독 결과를 그림별로 모아 판정합니다. 그림 오류를 확정하거나 기각하려면 해당 부분을 원본 해상도(100% 이상)로 확대해 본 기록(배율·영역)이 있어야 합니다. 축소 이미지 오판(과→파)을 막기 위한 장치입니다.
  • 표 편집기 P-03
    변환으로 풀린 셀 병합을 되돌립니다. 칸이 밀린 줄, 묶음 제목 줄, 각주 줄, 한 칸에 붙은 여러 항목을 자동으로 찾아 고칠 방법을 제안하고, 칸 병합·분할·줄·칸 넣기로 직접 고칩니다.
  • 스타일 가이드 버전 잠금
    작업 전에 가이드를 잠그고 책에 연결합니다. 잠긴 가이드는 고칠 수 없고, 잠긴 가이드가 없는 책은 작업을 저장할 수 없습니다. 작업마다 기준 버전이 기록되고, 가이드 규칙으로 문장을 자동 검사합니다.
  • 공용 용어집 P-11 · P-12 · P-13
    여러 편집자·역자가 같은 용어집을 실시간으로 함께 씁니다. 같은 영문에 다른 한글, 동음이의어, 옛 용어를 자동으로 경고하고, 원고 문장을 붙여 넣으면 용어를 검사합니다.
  • KMA 용어 대조 P-10
    용어집 한글을 대한의사협회 의학용어집과 대조합니다. 용어별로 KMA 검색 결과를 기록하고(저작권 때문에 통째 복사 안 함), 허락받은 자료가 있으면 자동 대조합니다. 다른 용어는 한 번에 표준어로 바꿉니다.
  • 권리 게이트 P-07
    책마다 산출물(종이책·전자책·웹뷰어·챗봇·AI 번역·오디오·영상)별 계약 권리와 추가 동의를 관리합니다. 권리가 없으면 배포 상태로 바꿀 수 없습니다.
  • 그림 대장 P-05
    그림마다 출처·허락된 산출물·인물 사진 동의를 기록합니다. 권리가 확인되지 않은 그림이 있으면 해당 산출물 배포가 막힙니다.
  • 원서 의문점 감수 P-18
    번역 중 찾은 원서 자체의 의문점을 감수자가 확인·기각·보류로 판정합니다. 확인된 항목은 한국어판 역주 목록과 원출판사 전달 목록(영문)으로 묶이고, 전달 기록이 남습니다.
  • 챗봇 거절 관리 챗봇 거절 사유 분리
    도서 챗봇이 답하지 않는 이유를 응급·위기, 진료 상담 거절, 책 밖 의료 정보, 책 밖 질문으로 나눠 안내합니다. 평가 세트로 판정 정확도(위기 놓침 포함)를 재고, 시험 대화의 틀린 판정을 평가 세트로 모읍니다.
  • TTS 비교 TTS 비교
    같은 낭독 원고를 기기 음성·성우 녹음·상용 음성으로 들어 보고 발음·의학용어·자연스러움·속도를 평가합니다. 낭독문은 원문에서 자동으로 만들고(인용번호·영문 병기 빼기, 발음 사전), 잘못 읽은 말은 발음 사전에 바로 넣습니다.
